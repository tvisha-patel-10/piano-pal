# 🎹 Piano Pal


A chord practice tool that lives in your browser. Learn new chords, drill them until they stick, then switch to free play and jam with a few different sounds.

I used to play synth in winter percussion, and I built this to get back into my prime chording era.

---

## 🕹️ How to Use

1. **🎓 Learn**: Pick a chord and see exactly which keys to press.
2. **🎹 Practice**: Play it on your keyboard until it feels natural.
3. **🎛️ Free Play**: Use a metronome and switch sounds and try the grand, electric, and synth modes.

---

## ✨ Features

- **Chord Practice Mode**: Learn chords and drill them at your own pace.
- **Free Play Mode**: Little piano sandbox for you to experiment with.
- **3 Sound Options**: Grand piano, electric piano, and synth.

---

## 🚀 Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/tvishapatel/piano-pal.git
cd piano-pal

# 2. Install dependencies
npm install

# 3. Start playing
npm run dev
```
